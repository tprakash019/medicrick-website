Privacy Policy

Last updated: November 22, 2026

Who uses the application

MEDICRICK BGMI Auto Shorts is a personal tool for its owner. It is not offered to the public.

Google data accessed

When authorized by the account owner, the application requests read-only access to Google Drive files so that it can find and download the owner's OBS gameplay recordings. The application does not need to delete or edit source recordings in Google Drive.

With separate YouTube authorization, it may upload the owner's generated videos to the owner's YouTube channel.

Use, storage and sharing

Authorized recordings are used to select highlights, transcode videos, and prepare uploads. Processing may take place using GitHub Actions and FFmpeg. Temporary video files and generated artifacts may be stored by the automation platform according to its configured retention period (typically seven days for generated artifacts). The owner controls the connected accounts and repositories. Content is not sold or used for advertising targeting.

Security and revocation

Access credentials should be stored as encrypted GitHub Actions secrets, not in public source files. The account owner can revoke third-party Google access from Google Account settings, and remove stored credentials from their GitHub repository.
